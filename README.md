# EduPintar - Platform Belajar Online

EduPintar adalah template website pembelajaran online modern yang dibangun menggunakan **React**, **Vite**, dan **Tailwind CSS**.

## Fitur Utama
- **Beranda Interaktif:** Dengan hero section, statistik, dan fitur unggulan.
- **Daftar Kursus:** Filter kursus berdasarkan kategori.
- **Detail Kursus:** Informasi lengkap mengenai kurikulum dan pengajar.
- **Halaman Pelajaran:** Antarmuka belajar yang bersih dengan navigasi antar pelajaran.
- **Responsif:** Tampilan optimal di HP, tablet, maupun desktop.

## Cara Instalasi
```bash
# Instal dependensi
npm install

# Jalankan mode pengembangan
npm run dev

# Bangun untuk produksi
npm run build
```

## Teknologi yang Digunakan
- React.js
- Tailwind CSS
- Lucide React (Icons)
- React Router DOM
